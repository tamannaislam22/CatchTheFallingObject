# Week 8 – Difficulty Increase

## Objective
To make the game harder automatically as the game continues.

## Tasks Completed
- Added automatic difficulty increase.
- Increased the number of falling objects gradually over time.
- Increased object speed slowly over time.
- Limited the maximum object speed to 5.
- Made the game harder automatically without changing the player's controls.
- Added extra object colors for the new falling objects.

## Technology Used
- Java
- Java Swing
- NetBeans IDE

## Difficulty System
- Game starts with 5 falling objects.
- The number of objects gradually increases up to 10.
- Object speed starts slowly and increases gradually.
- Maximum object speed is limited to 5.
- Difficulty increases automatically after a certain amount of time.

## Output
The game now becomes gradually harder as time passes by increasing the number and speed of falling objects.
