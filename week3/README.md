# Week 3: First Falling Object
## Objective
The objective of Week 3 is to add the first falling object to the game and make it move continuously from the top to the bottom of the screen.

## Tasks Completed

- Created a single falling object.
- Positioned the object at the top of the game screen.
- Made the object fall from top to bottom.
- Used a timer to control the falling movement.
- Added a reset system so that the object returns to the top after reaching the bottom.
- Kept the existing player/catcher and keyboard movement from Week 2 unchanged.

## Technology Used

- Programming Language: Java
- GUI Framework: Java Swing
- IDE: NetBeans

## Output

After starting the game, the falling object appears at the top of the screen and continuously moves downward. When it reaches the bottom of the screen, it automatically returns to the top and starts falling again.

## Result

Week 3 Successfully Completed.

The first falling object is working properly with continuous downward movement and automatic reset.
