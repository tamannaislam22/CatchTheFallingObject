# Week 6 – Score System

## Objective
To add a score system to the Catch the Falling Objects game so that the player earns points for successfully catching falling objects.

## Tasks Completed
- Added a score counter initialized to 0.
- Increased the score by 1 whenever an object is caught.
- Displayed the current score on the game screen.
- Integrated the score system with the existing collision detection.

## Technology Used
- Java
- Java Swing
- AWT Graphics
- Timer
- KeyListener

## Output
- Score is displayed at the top-left corner of the game screen.
- Score increases by 1 after every successful catch.
- Example: `Score: 0 → Score: 1 → Score: 2`
