# Week 9 – Game Over + Restart

## Objective
To add a Game Over system and allow the player to restart the game.

## Tasks Completed
- Added Game Over when lives become 0.
- Stopped the game when all lives are lost.
- Displayed a Game Over message on the screen.
- Displayed the final score after Game Over.
- Added a Restart button.
- Reset score and lives when the game is restarted.
- Reset the falling objects and difficulty system after restart.

## Technology Used
- Java
- Java Swing
- NetBeans IDE

## Game Over System
- The game starts with 3 lives.
- A life is reduced when an object is missed.
- When lives become 0, the game stops.
- A "GAME OVER" message is displayed.
- The final score is shown.
- The Restart button allows the player to start the game again.

## Restart System
When the Restart button is clicked:
- Score is reset to 0.
- Lives are reset to 3.
- Number of objects is reset to 5.
- Difficulty timer is reset.
- Falling objects are reset.
- The game starts again.

## Output
The game now shows a Game Over screen when all lives are lost and provides a Restart button to play the game again.
